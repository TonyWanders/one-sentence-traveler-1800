One sentence, at most 200 characters, explaining the modern internet to a
time traveler who has just stepped out of the year 1800. It uses only words
and pictures a person from 1800 already knows: a road, a post office, a
library, a letter, a book.

> Picture a road joining every post office and library on earth, so a letter you post reaches the far side of the world in a breath, and any book answers you at once.

## Run

```sh
python3 main.py
```

`main.py` writes the sentence to `/output/entry.txt` and prints it.
It is deterministic: every run produces the same bytes.
